# Дашборды платформы «Человек собаке друг»

Wireframe-макеты дашбордов для CRM-системы приюта для животных.

## 📋 О проекте

Подготовлены макеты двух дашбордов по ТЗ заказчика:

- **Дашборд 1 — Кристина (Супер-админ):** 4 витрины (Сводка, Воронка и качество, Финансы, Пристройство).
- **Дашборд 2 — Руководитель приюта:** 3 витрины (Оперативные списки, Животные, Финансы приюта).

## 🎨 Формат и инструменты

- **Инструменты:** Canva (десктоп), Miro (мобильный wireframe).
- **Формат:** Wireframe (схематичный макет без финального дизайна).
- **Мобильная вёрстка:** узкие экраны (телефон).
- **Метрики:** по ТЗ заказчика.
- **Подписи обновления:** real-time / daily / weekly.
